## 1. 模块 Mx + 子需求 Mx.y

两层编号，**全文唯一**，贯穿 prd → spec → progress → cycle → 快道调整日志。

```
M1 短链生成             ← 模块：业务价值单元（prd 切分）
  M1.1 创建短链          ← 子需求：独立可验的最小单元
  M1.2 短码生成算法
M2 短链跳转
  M2.1 正常跳转
```

### 规则

| 规则 | 说明 |
|---|---|
| 模块编号**锁定后不改** | 项目启动时一次性分配完所有 Mx。新增追加 Mn+1，废弃加 🗑，**永不重排** |
| 子需求编号**锁定后不改** | 新增追加 Mx.y+1，废弃加 🗑，**永不重排**，合并保留小编号大的标废弃 |
| 编号 = ID，**不暗示顺序** | 依赖关系用**需求树（mermaid flowchart）**画箭头表达 |
| 跨模块依赖**允许** | M2.1 依赖 M1.2 + M1.4，直接在需求树里画箭头 |

### 谁负责编

| 层级 | 谁分配 | 在哪分配 |
|---|---|---|
| 模块 Mx | brainstorm | prd.md §2 |
| 子需求 Mx.y | spec | spec.md §4 |

**brainstorm 只切 Mx，不管 Mx.y**。Mx.y 是 spec 的事——但必须归属 brainstorm 定义过的 Mx（MX 集合对账硬检查）。

### 废弃处理

| 场景 | 做法 |
|---|---|
| 整个模块废弃 | prd 标题加 🗑，spec 标题加 🗑，子需求不动 |
| 某个子需求废弃 | spec 标题加 🗑，PROGRESS.md 标 ⬜ + 备注原因 |
| 合并两个子需求 | 保留小编号，大编号标 🗑，内容合并进小编号 |

**不删除、不重排**。编号是永久引用。

## 2. 章节编号

spec / prd 的顶级章节用 `§数字`，子章节不加编号：

```markdown
# 项目名 — 技术规格

§0 元信息
§1 项目定位
§2 核心口径
§3 架构概览        ← 完整档才有
§4 功能需求
  #### M1.1 xxx    ← 子需求用 Mx.y，不用 §
§5 不在范围内
§6 待定项
§7 快道日志
```

**prd 同理**——§0 元信息 / §1 定位 / §2 模块 / §3 非目标 / §4 调整记录。

## 3. 状态后缀 emoji

所有文档（prd / spec / PROGRESS.md）统一用以下 emoji 标记模块/子需求状态。**只有 progress skill 有写权限**，其他文档里的是镜像：

| Emoji | 含义 | 出现位置 | 谁能写 |
|---|---|---|---|
| ⬜ | 未开始 | prd/spec 初始态；PROGRESS 未覆盖 | brainstorm 初始化写一次（之后不动） |
| 🟡 | 进行中（cycle 正在跑） | PROGRESS 子需求行；prd/spec 模块标题 | **只有 progress**（cycle 收尾时回写） |
| 🟢 | 完成（F1 对账过） | PROGRESS 子需求行；prd/spec 模块标题 | **只有 progress**（cycle 收尾时回写） |
| ⏳ | 当前游标（cycle 下次续做的起点） | PROGRESS 子需求行 | **只有 progress**（cycle 收点时设） |
| 🗑 | 废弃 | prd/spec 标题 | 任意 skill 发现废弃时改（改完要同步 PROGRESS） |

**禁止**：prd/spec 自己改 🟡🟢⏳。这些是 progress 的镜像字段，progress 回写之前永远是 ⬜。

## 4. 引用与锚点

### 文档间引用

```markdown
<!-- 引用另一个 Mx.y -->
详见 [M1.2](./spec.md#m12)

<!-- 引用整个模块 -->
[M2](./spec.md#m2)

<!-- prd/spec 互引 -->
技术规格见 [spec.md](./spec.md)
业务需求见 [prd.md](./prd.md)
```

### Anchor 生成规则

| 标题 | Anchor |
|---|---|
| `### M1 短链生成` | `#m1` |
| `#### M1.2 短码生成算法` | `#m12` |
| `§3 架构概览` | `#3` |

**锚点 = `#` + 小写 + 去掉 `.`**。GitHub / GitLab 的 markdown 自动生成 anchor 时会把 `M1.2` 变成 `m12`（去点小写），所以我们的引用格式要和这个一致——**不许写成 `#m1-2` 或 `#M1.2`**。

# agent-coding-rule

一套给 AI coding agent 用的**开发流程与文档规范化**技能集 —— 全局生效、单一真相源。

装上之后，agent 的手艺不再靠临场发挥：先头脑风暴再落文档，写实现代码前要你确认方案，说「做完了」之前必须跑验证，收尾先同步文档再分主题提交。

> 当前状态：设计定稿，技能文件尚未落地。

## 能力

| 能力 | 你会得到 |
|---|---|
| 需求分诊 · 头脑风暴 | 新需求先分清走快道还是完整流程；方案从发散到收敛，砍掉哪条带理由 |
| 标准化文档 | 需求文档、概要设计、架构设计、详细设计、开发进度各有固定结构与合格线，写完能自查 |
| 分级推进 | 按改动落点分档：改样式不必写设计文档，动架构必须全链走完 |
| 功能点循环 | 一个功能点从验收标准到测试证据走完一圈，不攒着最后一起验 |
| 存量项目文档重整 | 已有项目的老文档整理成标准结构，附一份待你补充的缺陷清单；原文档一律不动 |
| 全流程纪律 | 评审门槛、证据先于断言、分主题提交、文档回溯 —— 每个环节有闸门，不靠记性 |

## 安装

技能源在本仓 `skills/`，装到全局 `~/.claude/skills/acr-*/`，全局生效（规约不分项目）：

```bash
bash install.sh            # 安装 / 更新（仓库 → 全局）
bash install.sh --check    # 只比对，查全局与仓库是否漂移
```

装上后按场景自动触发，也可以直接点名调用。

## 文档

开发侧的规范文档（设计稿、注入审计）在本地 `docs/`，不进版本库 —— 它们面向「改它的人」，含个人工作习惯细节。使用者看本文件即可。
